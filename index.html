Temperature & Shock Monitoring
Live Machine Health Dashboard with ESP32

A live monitoring dashboard that tracks temperature and shock / vibration on a rotating machine, the two key wear indicators. It reads data from an ESP32 over WiFi (or from simulated data), plots it in real time against alert thresholds, and logs every shock or temperature event.

Live tracking of two wear indicators on a rotating machine: shock / vibration and bearing / motor temperature
Real-time charts with a red dashed alert threshold line on each graph
Connects to an ESP32 over WiFi by IP address to pull live sensor data, or runs on simulated data when disconnected
Shock detection: a spike that crosses the threshold, even briefly, is logged as a shock event
Temperature monitoring catches gradual problems like friction or lubrication loss, a different failure mode from sudden shock
Live readouts for shock level (g), temperature (°C) and alerts raised, with a NORMAL status indicator
Alert log of recent shock / temperature events, newest first, plus Simulate Shock and Reset controls for testing
